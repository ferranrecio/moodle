# Manager class PHPUnit tests

## Approach
Created a dedicated PHPUnit test file for the `manager` class covering all static creators, getters, `create_initial_sample_phase`, and `delete_activity_cascade`.

## Files created
- `public/mod/peerassign/tests/manager_test.php` — 13 tests, 48 assertions

## Tests covered
- `create_from_instance` — verifies correct instance, cm, and name
- `create_from_coursemodule` — verifies correct instance and cm
- `create_from_data_record` — with `peerassignid` field, with `id` field, and error on missing identifier
- Static creator equivalence — all three creators produce managers pointing at the same activity/cm/context
- `get_context` — returns correct `context_module`
- `get_course` — returns the course record matching the activity's course
- `get_renderer` — returns the plugin renderer instance
- `create_initial_sample_phase` — verifies phase defaults (phasetype, sequencenumber, required, unlockmethod, etc.)
- `delete_activity_cascade` — creates full object graph (phases, submissions, reviews, grades, phase completions) and verifies all are removed
- `path` attribute and `cmidnumber` on instance
