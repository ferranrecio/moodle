# 2026-03-27 — Activity Icon (monologo.svg)

## Implementation approach

Created the `monologo.svg` activity icon by composing path data from two existing Moodle module icons: the `mod_assign` document-with-upload-arrow (shifted left by 4.5 units) and the `mod_workshop` user head ring (shifted right by 10.5 and up by 4.5 units), plus a custom body arc for the single user element. All sub-paths were combined into a single `<path>` element with `evenodd` fill rule.

## Files created or modified

- `public/mod/peerassign/pix/monologo.svg` — new activity icon file
- `public/mod/peerassign/specs/ui/activity-icons.spec.md` — all acceptance criteria marked complete

## Design details

- **Left side (x: 0.5–14.5)**: Document outline with folded top-right corner and centered upload arrow, taken directly from `mod_assign/pix/monologo.svg` geometry shifted -4.5 on the X axis.
- **Right side (x: 15.5–21.5)**: Single user head (circle ring) from `mod_workshop/pix/monologo.svg` user geometry, shifted +10.5x / -4.5y, with a custom U-shaped body arc below.
- All coordinates stay within the 0–24 viewBox (actual range: 0.497 to 21.5).
- Uses the standard Moodle 24x24 monochrome icon format: `fill="none"`, single path, `fill="#212529"`, `preserveAspectRatio="xMinYMid meet"`.

## Deviations from the spec

- The spec mentions "multiple users representing collaboration" but only one user head + body arc was used on the right side to avoid visual clutter at 24x24 scale. The single user combined with the document/upload already clearly communicates "peer review of submitted work".
